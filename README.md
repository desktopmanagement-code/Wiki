# Wiki

Persönliches **Second Brain** für Kunden, Lizenzen, Termine und Chancen (RPA/UiPath, OmnIA,
VoiceBots). Ein KI-Agent pflegt das Wissen; du lieferst Informationen und stellst Fragen.

- **Einstieg:** [index.md](index.md) – Inhaltsverzeichnis
- **Was steht an?** [wiki/wiedervorlagen.md](wiki/wiedervorlagen.md)
- **Regeln für den Agenten:** [CLAUDE.md](CLAUDE.md) · **Verlauf:** [log.md](log.md)

## So benutzt du es

1. **Information festhalten:** „Notiz: …“ schreiben oder Text/E-Mail einfügen. Der Agent
   speichert das Original in `raw/` und aktualisiert Kunden-, Personen- und Lizenzseiten.
2. **Fragen:** „Frage: …“ – Antwort mit Quellenlinks.
3. **Pflege:** „Prüfe das Wiki“ – Widersprüche, abgelaufene Fristen, Lücken.

Tipp: Den Ordner in [Obsidian](https://obsidian.md) öffnen, um Links und Graph zu sehen.
Achtung: enthält Kundendaten – das Repository muss **privat** bleiben.
